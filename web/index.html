How this model works

Direct paths and first-order reflections use deterministic geometry. A visible doorway can route an obstructed source toward the opening. Up to six strongest first-order paths per source feed browser HRTF panners. A damped four-comb tail provides perceptual reverberation.

Material coefficients are illustrative broadband presets. There is no wave diffraction, measured calibration, architectural certification, or AI scene compiler. Raw mode is unprocessed mono with the wet tail muted. Local audio is never included in scene JSON and must be reattached after import or reload.
